# Video Workbench WB-1 Shared Fixtures And Interfaces

Date: 2026-09-18. Revision: 0.3.
Status: **W1-0/W1-1 PASS; WB1-MEDIA first admission slice locally verified.**

This document freezes the shared input vocabulary for the WB-1 media and
project packets. It is derived from the WB-0 contracts and the synthetic
media spike. It does not add routes, create a media registry or imply that
the implementation already exists.

## 1. Fixture Policy

The machine-readable catalog is
`tests/fixtures/video_workbench/manifest.json`. The catalog records only
synthetic files generated with local FFmpeg 7.0.2 on 2026-09-18. The checked-in
files are test inputs, not user media and not release assets.

Rules:

- Tests may read these files but must never upload them to a Provider.
- A fixture digest is an identity check, not permission to trust a browser
  supplied digest.
- The server recomputes SHA-256 and media metadata.
- Boundary fixtures such as oversized files, disk-full conditions and probe
  timeouts are generated in a test-owned temporary directory; they are not
  checked in.
- If a decoder version changes a generated byte stream, update the manifest
  only with a recorded runtime and review; do not silently accept a new hash.

## 2. Fixture Classes

| Class | IDs | Purpose |
| --- | --- | --- |
| Accepted video | `video_cfr_h264`, `video_av_aac` | normal picture and A/V import |
| Input-only video | `video_vp9_webm` | accepted input boundary; never an export promise |
| Timing validation | `video_vfr_h264` | rational time-base and VFR handling |
| Accepted audio | `audio_pcm_wav`, `audio_mp3` | independent audio import |
| Accepted stills | `still_png`, `still_jpeg`, `still_webp` | image import and still placement |
| Rejected media | `corrupt_mp4`, `playlist_m3u8` | corruption and network-playlist rejection |

The full bytes, dimensions, stream declarations, generation command and
SHA-256 are in the JSON manifest. The manifest's `runtime` is part of the
evidence and must be shown when a fixture is regenerated.

## 3. Shared Public DTOs

These examples are test-contract shapes, not Python implementation classes.
Unknown fields are rejected according to the core contract.

```json
  "byte_length": 198310,
  "state": "ready",
  "metadata": {
    "format": "mp4",
    "video_codec": "h264",
    "width": 640,
    "height": 360,

    "time_base": {"num": 1, "den": 15360},
    "audio_streams": 0,
    "rotation": 0
  },
  "preview_revision": 1

```

The public view excludes absolute paths, complete ffprobe output, prompts,
credentials, signed remote URLs and temporary worker paths.

### Library registration request

```json
{
  "library_kind": "video",
  "library_item_id": "gallery_exact_id",
  "expected_sha256": null
}
```

`library_item_id` is resolved server-side against an exact existing GenBox
identity. A filename substring, path, URL or browser-provided content hash
cannot select an item.

### Job view

```json
{
  "job_id": "job_synthetic_import_01",
  "operation": "import",
  "state": "preparing",
  "stage": "probe",
  "progress": null,
  "asset_ids": [],
```

When exact progress is unavailable, `progress` stays `null` and the client
shows stage plus elapsed time. Credentials, raw subprocess output and private
paths never appear in this view.

## 4. Error Mapping

| Condition | Code | Stage | Retryable |
| --- | --- | --- | --- |
| Missing/invalid request | `invalid_request` | admission | no |
| Missing login or CSRF | `auth_required` | auth | after auth |
| Wrong owner | `forbidden` | ownership | no |
| Unknown project/asset/job | `not_found` / `job_not_found` | lookup | no |
| Duplicate stale project save | `conflict` | save | after reload/save-as |
| Unsupported extension/codec | `unsupported_media` | admission/probe | no |
| Bad container or decode failure | `media_corrupt` | probe | no |
| Byte limit exceeded | `asset_too_large` | admission | no |
| Dimensions exceed 1920x1080 or 4096x4096 | `dimension_limit` | probe | no |
| Duration/project limit exceeded | `duration_limit` | probe/validate | no |
| Probe worker deadline | `probe_timeout` | probe | bounded retry |
| Missing ffmpeg/ffprobe | `dependency_missing` | startup/probe | after operator fix |
| Reserved storage unavailable | `disk_space` | staging/publish | after cleanup |
| Owned worker cancellation | `job_cancelled` | worker | explicit retry |
| Cleanup still pending | `cleanup_pending` | cleanup | observe/retry |
| Unhandled safe boundary failure | `internal` | any | no automatic retry |

The public message is localized and safe. Raw exceptions, command lines,
credentials, signed URLs and absolute paths are retained only in protected
diagnostics where permitted by the existing application policy.

## 5. Auth, Ownership And Boundary Matrix

| Operation | Auth | CSRF | Ownership | Path/URL rule | Evidence |
| --- | --- | --- | --- | --- | --- |
| External import | required | required for browser mutation | request/job owner | multipart only; no URL | VA-02/13 |
| Library register | required | required | exact library item visible to owner | no substring/path input | VA-03/13 |
| List assets | required | no mutation CSRF | owner-scoped | preview handle only | VA-03/13 |
| Create/read project | required | create/save mutation protected | project owner | opaque project ID | VA-01/13 |
| Save project | required | required | project owner + expected revision | no absolute paths | VA-01/13 |
| Read/cancel job | required | cancel requires CSRF | job owner | opaque job ID | VA-12/13 |
| Thumbnail/range/download | required | no mutation CSRF | referenced asset owner | final confined path | VA-03/13 |

No browser request may contain shell text, provider credentials, arbitrary
filesystem paths, callback URLs or upstream request bodies. Any such field is
rejected as `invalid_request` before worker creation.

## 6. W1-1 Exit Evidence

W1-1 is ready for the media and project packets when:

1. The manifest and checked-in fixture bytes agree on size and SHA-256.
2. Both packets cite the same asset/project/job DTO examples and error table.
3. Auth, CSRF, ownership and path-boundary expectations are identical in both
   packet test plans.
4. No fixture requires a network fetch, user media, Provider call or deletion.
5. A manifest mismatch fails the test setup rather than silently refreshing
   the expected hash.

W1-1 does not create an endpoint or mark any VA case as passed.
